# 0x02. C - Functions, nested loops

This project covers writing C functions, using nested loops, and printing
characters with a custom `_putchar` function.

## Requirements

- Ubuntu, compiled with `gcc -Wall -pedantic -Werror -Wextra -std=gnu89`
- Code follows the Betty style
- No global variables, and no more than 5 functions per file

## Files

| File | Description |
|------|-------------|
| `_putchar.c` | Writes a character to stdout |
| `main.h` | Header file with function prototypes |
| `0-putchar.c` | Prints `_putchar` followed by a new line |
