# 0x04. C - More functions, more nested loops

This project covers more C functions and nested loops, including character
checks, drawing shapes in the terminal with `_putchar`, and FizzBuzz.

## Requirements

- Ubuntu, compiled with `gcc -Wall -pedantic -Werror -Wextra -std=gnu89`
- Code follows the Betty style
- No global variables, and no more than 5 functions per file
- Only `_putchar` is used for output (except where the task allows the
  standard library)

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with function prototypes |
| `0-isupper.c` | Checks for an uppercase character |
