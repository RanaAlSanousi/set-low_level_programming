# 0x05. C - Pointers, arrays and strings

This project covers pointers, arrays, and strings in C, including swapping
values, string length, reversing, and copying strings.

## Requirements

- Ubuntu, compiled with `gcc -Wall -pedantic -Werror -Wextra -std=gnu89`
- Code follows the Betty style
- No global variables, and no more than 5 functions per file

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with function prototypes |
| `0-reset_to_98.c` | Updates the value an int pointer points to, to 98 |
