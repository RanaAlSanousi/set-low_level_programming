# 0x03. C - Debugging

This project covers debugging C programs: reading code carefully, testing
with multiple main files, and fixing logic errors.

## Requirements

- Ubuntu, compiled with `gcc -Wall -pedantic -Werror -Wextra -std=gnu89`
- Code follows the Betty style

## Files

| File | Description |
|------|-------------|
| `0-main.c` | Main file that tests `positive_or_negative` with 0 |
| `main.h` | Header file with function prototypes |
